# oap-bootstrap

> **Archived.** Retired with the Open Agentic Platform.

oap-bootstrap stood up an open-agentic-platform instance in a new GitHub org
and brought its Hetzner K3s estate online in one resumable CLI. The platform
it bootstrapped has been superseded by
[statecraft](https://github.com/statecrafting/statecraft), whose fleet plane
operates stamped [enrahitu](https://github.com/statecrafting/enrahitu) apps on
hetzner-k3s clusters, so a standalone org-forking bootstrapper is no longer
part of the family.

The family front door is [statecraft.ing](https://statecraft.ing). The
original README and the full codebase remain in this repository's git history.
