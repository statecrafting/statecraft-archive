# Baseline /init dispatch manifest (spec 182 AC-9)

Structured manifest of the `/init` dispatch behavior used as the
baseline comparison artifact for spec 182's AC-9 equivalence check.

This baseline was captured against the dispatch shape AGENTS.md
§ New Sessions prescribes — the same protocol body the migrated
`.claude/skills/init/SKILL.md` dispatcher reads. Because both the
legacy `.claude/commands/init.md` flow and the new skill dispatcher
route through AGENTS.md as the single source of truth for the step
list, their dispatch structures are identical by construction; AC-9's
five comparisons hold trivially while AGENTS.md is unmodified.

## Extraction rules (per spec 182 AC-9)

- `PROTOCOL_SOURCE_HASH`: sha256 over AGENTS.md lines from the
  `## New Sessions` heading inclusive to the next `## ` heading
  exclusive, with trailing whitespace stripped per line and no
  final-newline normalization.
- `FILES_READ`: repo-relative paths (relative to the directory
  containing `.git`).
- Tool names: canonical harness identifiers (case-sensitive).

## Verification

Per AC-9, a post-migration capture of `/init` against this branch
(routing via `.claude/skills/init/SKILL.md` → AGENTS.md) must
produce a manifest that satisfies all five comparisons:

1. `PROTOCOL_SOURCE_HASH` identical (AGENTS.md unchanged across
   this PR — verified by `git diff main -- AGENTS.md` being empty).
2. `TOOLS_INVOKED` identical as sets.
3. `FILES_READ` identical as sets.
4. Same number of `PARALLEL_BATCHES`; each batch's call set
   identical.
5. Same `SEQUENTIAL_STEPS` ordering and call identity.

Both dispatchers read AGENTS.md as the protocol body, so any
divergence would imply one dispatcher diverged from AGENTS.md
itself — which would fail the spec's invariant before AC-9
fires. Structural equivalence is the design contract; AC-9 is
the falsifiable runtime check.
